# Mozilla Splash Page 🌐🔥

This is a simple splash page project inspired by Mozilla, built as part of an HTML media embedding challenge.

## 📄 What it Includes

- A styled Mozilla-themed page using basic HTML and CSS
- Embedded YouTube video
- Linked Mozilla-related resources with images
- A red panda image for fun!
